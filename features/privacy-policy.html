1. About This Policy

RAVUKSA FINTECH is a Financial Education & Market Learning platform. This Privacy Policy explains information practices associated with our website, account services and educational features.

This policy describes the website functionality identified during our technical review. Actual practices may also depend on third-party service configurations and applicable requirements.

2. Information We May Collect

Depending on the features used, the platform may process the following information:

  • Name and username provided by the user.
  • Email address associated with account registration and login.
  • Profile information such as bio and learning level.
  • Learning activity, topic completion and quiz progress, where saved.
  • Feedback rating and feedback message submitted by the user.
  • Basic technical information processed by hosting, browser or service providers.

Please do not submit passwords, OTPs, banking credentials or confidential financial information through public forms.

3. Account Registration & Firebase Authentication

RAVUKSA FINTECH uses Google Firebase Authentication for email and password registration, login and logout.

During registration and login, Firebase Authentication processes the account information required to provide these services. The website uses the authenticated user's account identity to support profile functionality.

Google sign-in, email verification and password-reset functions are not currently confirmed as implemented in the website's user-facing code. Their availability in the Firebase Console does not mean these features are available on the website.

Official reference: Firebase Privacy and Security

4. Profile & Learning Information

Our website uses Firebase Cloud Firestore to store profile information and associated learning progress where these features are used.

The identified profile fields may include:

  • User ID (UID) and account email address.
  • Name and username.
  • Bio and learning level.
  • Topics started and topics completed.
  • Quiz progress and overall learning progress.
  • Profile update timestamp.

Profile records are stored in the profiles Firestore collection and associated with the authenticated user's UID.

Current Firestore security rules restrict profile reading and writing to the authenticated user whose UID matches the profile document ID.

5. Feedback Information

When an authenticated user submits feedback, the website sends information to the Firestore feedback collection.

The identified feedback fields include:

  • User ID (UID).
  • Account email address.
  • Rating submitted by the user.
  • Feedback message.
  • Submission timestamp.

Under the current Firestore rules, authenticated users can create feedback records, while client-side reading, updating and deleting of feedback records are denied.

The current create rule does not independently verify that the UID submitted in the feedback record matches the authenticated user's UID.

6. Database Location & Firebase Storage

Our reviewed Firebase Cloud Firestore database uses the location identifier nam5.

The two Firestore collections identified during our review are profiles and feedback.

Firebase Storage is not currently set up in the Firebase project based on the configuration reviewed. This statement does not cover other hosting or third-party storage services.

Firebase services are subject to Google's applicable privacy and service terms. Read Firebase Privacy Information .

7. Local Storage & Offline Functionality

The website uses browser local storage for limited daily-learning interface information.

The identified local storage keys are:

  • ravuksaDailyLearningDate: stores the daily learning date.
  • ravuksaDailyLearningIndex: stores the current daily learning item index.

These values support the daily-learning interface and are separate from the Firebase account password.

Our service worker also uses browser caching for the website homepage and web app manifest to support basic offline access.

Other browser, hosting or third-party services may use their own technical storage mechanisms.

Certain market-data features may use IndianAPI. Market information may be delayed, incomplete or subject to provider limitations.

Third-party providers operate under their own privacy policies, terms and technical practices. We do not control their independent data-handling practices.

We do not claim that market-data providers receive user profile or feedback information unless such processing is specifically disclosed.

10. Data Security

Our reviewed implementation uses Firebase Authentication and Firestore security rules to control access to account-related and database functions.

Current rules restrict profile access by authenticated user UID and deny client-side reading, updating and deleting of feedback records.

No internet-based service or electronic storage system can be guaranteed completely secure. We do not make an absolute guarantee against unauthorized access, data loss or service interruption.

Users should never share passwords, OTPs, banking credentials or confidential financial information through public forms or messages.
